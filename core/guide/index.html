Install Certifyd Core

This guide covers the packages published for v0.1.0-beta.27. Choose the package for your operating system and processor, then follow its installation path. The downloads page and this guide are generated from the same reviewed release record.

Choose your download

Windows x64

Run the Windows x64 installer, then launch Certifyd Core from the Start Menu or desktop.

Certifyd-Core-Setup-0.1.0-beta.27-win-x64.exe

This installer is unsigned; Windows may show a warning. Confirm the exact filename and hash before proceeding.

macOS Apple Silicon and Intel

Choose the DMG for Apple Silicon or Intel, open it, drag Certifyd Core.app to Applications, then open the app.

  • Apple Silicon: Certifyd-Core-0.1.0-beta.27-macos-arm64.dmg
  • Intel: Certifyd-Core-0.1.0-beta.27-macos-x64.dmg

These DMGs are signed and notarized per the release validation. Stop if Gatekeeper reports a different result.

Linux x64 and ARM64

On a Debian-compatible desktop, open the matching .deb with the graphical package installer, then launch Certifyd Core from the application menu.

  • x64: Certifyd-Core-0.1.0-beta.27-linux-x64.deb
  • ARM64: Certifyd-Core-0.1.0-beta.27-linux-arm64.deb

For an advanced portable install, extract the matching .tar.gz and run ./start.sh from the extracted folder.

  • x64 portable: Certifyd-Core-0.1.0-beta.27-linux-x64.tar.gz
  • ARM64 portable: Certifyd-Core-0.1.0-beta.27-linux-arm64.tar.gz

The portable command applies only to the extracted archive. Physical Raspberry Pi installation is not claimed here.

Open the local dashboard

Open http://127.0.0.1:4000 on the computer running Core if the dashboard does not open automatically.

The dashboard is private to the Core computer by default. Installing Core does not enable public sharing.

Create your first owner

  1. On the local sign-in screen, choose New here?, complete Create owner, and keep any recovery material private.
  2. Sign in and confirm that the real dashboard loads. On an existing installation, sign in with the existing owner instead of creating another one.
  3. Close Core and reopen it to confirm it returns to the local dashboard.

Do not share passwords, recovery material, creator keys, or wallet credentials in screenshots or support requests.
