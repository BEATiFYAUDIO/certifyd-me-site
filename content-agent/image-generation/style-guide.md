# Certifyd Blog Image Style Guide

Use this guide only for Blog Engine cover-image generation.

## Editorial Style

- Editorial music-business and creator-infrastructure imagery.
- Analog, tactile, magazine-style photography or photo collage.
- Strong central object with clear foreground/background separation.
- Dark or restrained environments with selective cyan, purple, amber, or white highlights.
- Compositions must work as landscape blog covers and survive cropping to social formats.

## Avoid

- Generic artificial-intelligence imagery.
- Corporate stock-photo people.
- Dashboards, UI screenshots, floating icons, globes, network diagrams, and abstract data streams.
- Text baked into the image unless explicitly requested in the image brief.
- Fake Certifyd logos or invented brand marks.

## Brand Handling

Do not ask the image model to render the Certifyd logo. If branding is needed, the application composites the exact canonical logo after image generation.
