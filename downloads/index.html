Optional Verification

Verify a download

SHA-256 checksums are for advanced users who want to verify that a downloaded file matches the validated build. Normal installation does not require this step.

Windows

In PowerShell, compare the hash with the SHA-256 value listed on the platform card.

Get-FileHash .\Certifyd-Core-Setup-0.1.0-beta.10-win-x64.exe -Algorithm SHA256

macOS or Linux

In Terminal, compare the output with the SHA-256 value listed on the platform card.

shasum -a 256 ./Certifyd-Core-0.1.0-beta.10-macos-arm64.dmgsha256sum ./Certifyd-Core-0.1.0-beta.10-linux-x64.tar.gz
